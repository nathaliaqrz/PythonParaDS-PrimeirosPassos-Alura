# 📌 Python para Data Science: Primeiros Passos

### 📖 Sobre o Projeto

Este repositório contém materiais e exercícios introdutórios sobre Python para Data Science, abordando conceitos fundamentais da linguagem e sua aplicação prática. Curso realizado na plataforma da Alura Cursos Online de Tecncologia.

### 🎯 O que Aprendi

Durante os estudos, explorei os seguintes tópicos.

✅ Comandos Básicos de Python;

✅ Tipos de Variáveis.

✅ Manipulação de Dados.

✅ Estruturas Condicionais – Uso de if, else e elif para controle de fluxo.

✅ Estruturas de Repetição – Implementação de loops como for e while.

✅ Estruturas de Dados – Introdução a listas, tuplas, conjuntos e dicionários.

✅ Aplicação Prática – Relacionando conceitos da linguagem à construção de projetos.
